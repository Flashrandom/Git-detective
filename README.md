# GitHub Profile Search 🔍

A clean, responsive web application that dynamically fetches and displays GitHub user profiles using the GitHub REST API. 

## 🚀 About The Project
I built this project to strengthen my core JavaScript fundamentals, specifically focusing on API integration and asynchronous programming. It takes a GitHub username as input and renders their profile details (avatar, bio, followers, repos) in a clean UI card.

## 🛠️ Tech Stack
* **HTML5:** Semantic structure
* **CSS3:** Custom styling and responsive flexbox layout
* **Vanilla JavaScript (ES6+):** Core logic without any external libraries
* **GitHub REST API:** Real-time data fetching

## 🧠 What I Learned
Working on this project helped me practically understand:
* Using `fetch` along with `async/await` for asynchronous API calls.
* Handling HTTP errors gracefully (e.g., catching 404 Not Found when a user doesn't exist).
* Dynamically manipulating the DOM and injecting HTML using ES6 Template Literals.
* Structuring a project cleanly by separating HTML, CSS, and JS into distinct files.
